# Clinical Figure Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create reviewable, clinically grounded drafts for Figures 1 and 5 without altering the current cited manuscript figures until the author selects them.

**Architecture:** A versioned Matplotlib source will compose text, measurements, and report content from manuscript-controlled values. A text-free, synthetic raster MRI illustration may be generated as a supporting insert, but no generated image may carry labels, values, or claims. Draft PDF and PNG assets will be placed beside the existing figures under a `drafts` directory.

**Tech Stack:** Python, Matplotlib, existing synthetic-slice helpers, built-in image generation, Tectonic.

**Spec:** `docs/superpowers/specs/2026-11-04-clinical-figure-redesign-design.md`

## Global Constraints

- Redesign `fig1_system` and `fig5_report` only. Do not alter data-bearing Figures 2--4.
- Use synthetic, non-patient imagery. Generated raster artwork must contain no text.
- Keep all numbers, cohort names, and methodological claims in code-controlled text.
- Create versioned drafts before replacing a cited figure or modifying `paper/main.tex`.
- Preserve the restrained journal palette, accessible contrast, and vector PDF output.

## Review Focus

- The Figure 1 draft must make the scan-level clinical question visible before the system mechanics; inspect this in the exported PNG.
- No generated image may imply a real patient scan or include unreadable/generated text; inspect the source asset before composition.
- All displayed values must match the existing synthetic example and report-check totals; compare code literals with the current Figure 1 and Figure 5 sources.
- The draft must remain legible at the manuscript’s printed width; compile the paper with the selected draft only after author approval.
- The current cited figures must remain byte-for-byte untouched until the author selects a draft.
