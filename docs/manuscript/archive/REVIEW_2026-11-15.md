# Review of paper/main.tex (methods-rewrite draft, commit 582d269), 2026-11-15

Two reads of the full main.tex: a stern methods review (Part A) and an audit against the four failure modes of
Buschek, "When LLMs Write Our Papers" (2025) (Part B, separate agent). The plan that acts on them is in
OUTLINE.md ("System-first submission version, 2026-11-15"). Line numbers refer to main.tex at 582d269.

## Part A. Methods review

### Done well (keep)
1. Plans committed with hashes before each test. Nulls reported (second segmentation, added inputs, deep networks,
   M2, 32% direction words).
2. Models locked, then applied unchanged at two external centres. Patient-grouped CV and a patient-level bootstrap.
3. An exact AUC split with a context-only counterfactual score.
4. A size-matched marginal baseline for the group conformal sets.
5. Errors written independently of the verifier's rules, with correct paraphrases as controls.
6. Limits stated plainly ("No clinician has read the reports").

### Problems (most serious first; corrected after a self-check)
1. **The label sampling ties time to label.** 56/62 progression scans fall later than 12 weeks, and 51/84
   non-progression scans fall within 12 weeks. The clinical-history model also gets visit index and days since
   diagnosis. State this as part of the argument; do not leave it implicit.
2. **A_B > A_W is descriptive, not proof of reliance on context.** Real tumour differences between windows can
   produce it, so context reliance is shown only by the context-only score. 90% of the W pairs come from the later
   window. Add AUCs per window.
3. **The context-only score is defined two ways.** L214–215 say "computed once", but the Fig 3 caption says it
   varies between folds. The 0.93 is the fold-wise planned value (METHODS_RESULTS line 24). "Computed once" is
   exploratory E1, which used every labelled MU scan.
4. The LUMIERE window is the rater's own flag. The paper already says the flag carries the result (L466). Name the
   flag as the rater's. (The original review overstated this as leakage.)
5. **Incorporation bias goes unnamed.** The LUMIERE label is a rating of the scan, and at UCSF 27/29 progression
   scans had increased enhancement (enhancing volume alone 0.88).
6. **Intervals and multiplicity.** The bootstrap resamples held-out predictions without refitting. Groups of 9
   scans are quoted. The case for skipping multiplicity correction (L382) is weak, so name the primary results.
7. **Conformal validity is approximate under patient weighting.** Cite a hierarchical-conformal result or say so
   plainly. Singleton and empty rates exist (NUMBERS.md line 406, METHODS_RESULTS M2) and should be shown next to
   coverage.
8. **Calibration slope and intercept of the base scores are missing.** Brier by tier exists (NUMBERS.md S4). The
   TRIPOD+AI checklist exists (CHECKLIST_TRIPOD_AI.md) but is not cited.
9. **Deviations from the plan are reported as passes.**
   - Report checker: every LUMIERE report failed, the prompt was revised, and the test is reported as "Yes".
   - Verifier: v1.0 rejected every evaluation report, v1.1 was written afterwards, and Table 2 shows "Yes" under
     "Rule fixed in advance".
10. **The verifier's recall on errors the language model makes on its own is unknown.** The one MU report it
    rejected was never read, although MU is public and the report can be read locally. The "independent" errors were
    written by an LLM agent, which the AI-use statement must say.
11. **The template passed every check too.** Frame the verifier as independent of the writer, and the language
    model as one writer under test.
12. **The audits did not run at UCSF.** Keep the cross-site wording exact.
13. **Reproducibility.** The data and code statements are still to do. Give exact LLM identifiers. The volumes are
    noisy (median 2.6-fold change within 30 days), so the checks show fidelity to the record, not correctness.

### 3. Misrepresented citations
- **wiseman2017.** A learned extractor used as an evaluation metric, not a deterministic check.
- **janes2009.** The AAUC is case-weighted, while A_W is pair-weighted. Call A_W "a pair-weighted analogue". Cite
  janes2008 for the conceptual point.
- **ding2023.** It clusters classes by data. For a fixed fallback to coarser groups, cite johansson2015.
- **romano2020 and barber2021limits.** Neither covers patient weighting. Move the citations to the subgroup clause.
- **kryscinski2020.** Error injection there trains FactCC; its evaluation uses human labels.

### 2. Performative or weak citations
- **geirhos2020 and zech2018 for "shortcut learning".** The dates are a deliberate input, so keep badgeley2019 only.
- **L58 "rarely measured".** No citation, and matos2026, tsue2023, romano2020 and lu2022 measure these properties.
- **Poor matches:** damour2022 (underspecification); nam2026 (gates for manuscript preparation); mitchell2019 (a
  static model card); taal2008 (supports "frequent", not "most common").
- **Bibliography:** confirm the zeba2026 volume and the pham2026 venue. tsue2023 and matos2026 are arXiv only.
- **Verdict OK:** wen2023, badgeley2019, kallus2019, matos2026, vovk2022book, angelopoulos2023, mehrtens2025,
  weinberg2018, gabriel2021, rao2025rexerr, mansour2026, varoquaux2018 and the dataset papers.
