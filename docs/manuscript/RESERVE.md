# The reserve: questions we leave to the reviewers

Results that are true, checked and ready, but deliberately not in the main text (the 80 / 20 rule,
[STYLE.md](STYLE.md) section 4). Each row gives the likely reviewer question, the short answer, and where the full
answer lives. When a reviewer asks, the response quotes the answer and points to the supplement section or result
document.

The reserve follows the current paper (`paper/main.tex`, `paper/supplement.tex`); it was consolidated on 2026-11-19,
and the earlier version, with rows on analyses no longer in the paper, is in git history (the earlier supplement at
commit b10f670). Main-text pointers use the printed numbering (Tables 1 to 5, Figures 1 to 7); supplementary pointers
use the printed S numbers.

Rule: an item may sit here only if it leaves the paper's conclusion unchanged. Anything that would change what a
reader concludes belongs in the main text.
